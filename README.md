# EduSource.lk — Ultimate Sri Lankan Advanced Level (A/L) Hub

EduSource.lk is a comprehensive, multilingual web ecosystem designed to centralize, streamline, and elevate the academic journey of Sri Lankan Advanced Level (A/L) students across all subject streams (Math, Science, Commerce, Arts, and Technology).

Instead of navigating scattered social media groups and unverified file drives, EduSource provides a single, structured hub that connects students with top-tier tuition options, community-vetted study materials, and instant performance-testing tools.

---

## 🌟 Core Features

* **Class Finder & Student Reviews:** An open directory tracking local and online tuition classes across the island. Students can search, review, and rate tutors based on teaching quality, clarity, and pacing.
* **Crowdsourced Study Material Repository:** A dual-purpose archive where students and educators can upload, discover, and download structured lecture notes, short-notes, and past term-test papers.
* **Interactive Testing Engine:** A custom, state-driven multiple-choice question (MCQ) engine that delivers real-time validation, color-coded answer feedback, and performance breakdowns.
* **Stream-Agnostic & Multilingual:** Engineered to natively support formatting requirements and character sets for both **English** and **Sinhala** across any educational stream.

---

## 🛠️ Technology Stack

EduSource is built using a decoupled full-stack architecture optimized for fast page loads, highly interactive UI flows, and enterprise-grade security.

* **Frontend:** Built with **React.js (.jsx)** powered by Vite for a lightning-fast, reactive component architecture. UI styling is managed via **Tailwind CSS** to maintain a clean, fully responsive light-mode interface across mobile devices and desktops.
* **Backend:** Driven by a **Spring Boot (Java)** REST API layer that handles business logic, database transaction security, and secure route filtering using tokenized headers (`Authorization: Bearer <token>`).
* **Database:** Powered by a document-oriented NoSQL **MongoDB** cluster, allowing fluid storage of deeply nested content matrices (such as diverse question configurations and polymorphic study materials).

## 🚀 Future Enhancements

* **AI-Powered Resource Recommendation:** An intelligent suggestion engine that analyzes a student's quiz history and weakness points to automatically recommend specific study notes, papers, or nearby classes.
* **Real-Time Tutor-Student Marketplace:** Integrated booking systems allowing tutors to update schedules, list crash courses, and accept registrations directly through the platform.
